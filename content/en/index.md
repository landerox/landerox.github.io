## Interactive Tools

Try a failure scenario, replay an agent crash or size an evaluation. These
tools run in your browser with examples you can change.

<!-- markdownlint-disable MD003 MD013 -->
<div class="grid cards labs-grid" markdown>

* :material-alert-circle-outline: **Failure Lab · Pipeline Simulator**

    Pause a worker or interrupt writes, then inspect the recovery. Compare
    retry policies against the same simulated incident.

    [:octicons-arrow-right-24: Open Failure Lab](projects/tools.md#failure-lab)

* :material-file-multiple-outline: **Table Files · Compaction Planning**

    Estimate how many files a table keeps from its daily volume, commit
    rhythm and partitioning, before and after compaction.

    [:octicons-arrow-right-24: Open Table Files](projects/tools.md#interactive-table-planner)

* :material-robot-outline: **Agent Replay · Crash Recovery**

    Crash an agent between a write and its checkpoint, then compare four
    recovery strategies and see which ones apply the write twice.

    [:octicons-arrow-right-24: Open Agent Replay](projects/tools.md#interactive-agent-run)

* :material-chart-bell-curve: **Eval Statistics · Error Bars**

    Put an interval around a pass rate before trusting it, then size a
    comparison between two variants.

    [:octicons-arrow-right-24: Open Eval Statistics](projects/tools.md#interactive-eval-stats)

</div>
